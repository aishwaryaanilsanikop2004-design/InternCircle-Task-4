# Personal Expense Tracker

## Description
A Python-based Personal Expense Tracker that records daily expenses and stores them in a CSV file.

## Features
- Add expenses
- View all expenses
- Filter expenses by category
- Category-wise expense summary
- CSV file storage

## Technologies Used
- Python
- CSV module
- File handling

## Files
- main.py - Main Python program
- expenses.csv - Stores expense records
- README.md - Project information

## Expected Outcome
Learn structured data storage and file I/O operations using Python.
